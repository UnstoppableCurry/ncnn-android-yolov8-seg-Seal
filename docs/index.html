03

从代码读到的结构

推断链写在 ndkcamera、yolov8ncnn.cpp 与 yolo.cpp。下列数字均来自默认参数或常量，不是评测报告。

  1. 相机 Android NDK Camera2（camera2ndk + mediandk）。README：使用 NDK 相机以追求效率；过旧设备若缺少 HAL3 可能崩溃。
  2. 预处理 RGB 帧按 target_size = 640 等比缩放，再 pad 到 32 的倍数（MAX_STRIDE）。PIXEL_RGB2BGR，均值按 0 减，归一化为 1/255。
  3. ncnn 网络 输入 blob 名 images。输出 output0（检测）与 output1（mask proto）。param 文件与 JNI 抽取名称一致。
  4. 解码 网格步长 8, 16, 32；num_class = 11；DFL reg_max = 16；mask 特征 32 维。默认 prob_threshold = 0.4，nms_threshold = 0.5。
  5. 掩膜 decode_mask：特征与 proto 做 MatMul → Sigmoid → Reshape → 去 pad → 4× 上采样到原图。绘制时掩膜阈值 0.5。
  6. 叠加 画框、半透明类别色、英文类别名与分数。另有 10 帧滑动平均的 FPS 文字，仅供画面阅读，本页不引用其数值。

04

README 里的运行说明

摘自「2 Some notes」，不改原意。

  • Android NDK 相机被用来追求效率。
  • 过旧设备若缺少 HAL3 相机接口，可能崩溃。
  • 所有模型都经过手工修改，以接受动态输入尺寸。
  • 多数小模型在 GPU 上往往慢于 CPU，这是常见现象。
  • 暗光下 FPS 可能更低，因为相机曝光时间更长。

05

如何在设备上运行

完整步骤见 仓库 README。这里只列 CMake 与构建文件里写明的依赖。

  • 依赖 ncnn 与 opencv-mobile。CMake 示例路径为 ncnn-20221128-android-vulkan、opencv-mobile-4.6.0-android。
  • YOLOv8 转 ncnn 的说明在上游 wiki：Convert yolov8 model to ncnn model。
  • 用 Android Studio 打开工程后编译安装。应用包名 com.tencent.yolov8ncnn，界面名 ncnn-yolov8-seg。
  • app/build.gradle：minSdkVersion 24，ABI 仅 arm64-v8a。AndroidManifest 版本名 1.1，竖屏，申请 Camera 权限并声明 camera2.full。

源码文件头标注 Tencent ncnn 示例的 BSD 3-Clause。本页是该 Android 印章分割仓库的静态展示，不是官方产品站。
